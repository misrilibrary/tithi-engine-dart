tithi_engine

tithi_engine library

Accurate Vedic tithi, lunar month, and festival date calculator.

import 'package:tithi_engine/tithi_engine.dart';

final panchang = Panchang(MonthSystem.purnimant);
final info = panchang.forDate(DateTime(2026, 2, 15), City.ujjain);
print(info.displayName); // "Phalguna Krishna Trayodashi"

Enums

Lunar month determination from Sun's sidereal position. The twelve months of the Hindu lunar calendar.
MonthSystem
Month system: Purnimant (North India) or Amant (South India).
MuhurtaRule
Muhurta rule that determines the observance day for a festival.
Paksha
Core tithi calculation and naming. The two fortnights (pakshas) of a lunar month.

Constants

defaultCity → const String
The single default reference city used wherever no city is specified (month/tithi resolution, sunrise, UI defaults). Change this one value to swap the app-wide default. Must exist in supportedCities.
festivals → const List<FestivalDef>
All supported festivals.
supportedCities → const Map<String, CityLocation>
All supported cities for tithi calculation. To add a city: add an entry here, then generate its correction table (tools/benchmark/bin/gen_city_corrections.dart) and run test/gen_registry.dart.
tithiNames → const List<String>
Tithi names within a paksha (1-15).

Functions

calculateTithi(double moonLongitude, double sunLongitude) → int
Calculate tithi number (1-30) from Moon and Sun sidereal longitudes. 1-15 = Shukla Paksha (waxing), 16-30 = Krishna Paksha (waning).
convertMonth(LunarMonth month, Paksha paksha, {required MonthSystem from, required MonthSystem to}) → LunarMonth
Convert a lunar month between Purnimant and Amant systems.
findFestivalDate(FestivalDef fest, int year, String city, TithiCalculator calc) → FestivalDate?
Find the correct festival date for a given year and city, applying muhurta rules. Festival definitions use Purnimant month names, so finding always uses Purnimant internally.
findRecurringDates(FestivalDef fest, int year, String city, TithiCalculator calc) → List<FestivalDate>
Find all occurrences of a recurring tithi in a year.
getLocationForCity(String city) → CityLocation
Get location for a city. Falls back to the default reference city if unknown.
getPaksha(int tithiNumber) → Paksha
Get paksha from tithi number (1-30).
getTithiName(int tithiNumber) → String
Get tithi name from tithi number (1-30).
tithiInPaksha(int tithiNumber) → int
Get tithi position within paksha (1-15).
