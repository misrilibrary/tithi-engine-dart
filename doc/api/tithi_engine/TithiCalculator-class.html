findTransitionTime(DateTime date, {Duration? utcOffset}) → DateTime?
Find the transition time between two adjacent tithis on a given date. Returns the UTC DateTime when tithi changes from fromTithi to toTithi, or null if the transition doesn't occur on that day. Binary search: ~11 iterations for 1-minute precision.
